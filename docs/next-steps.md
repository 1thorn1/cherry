- 참고: `user.friend_code`는 V1 마이그레이션 때부터 이미 있음 (스펙에서 "v1.0부터 미리 발급" 요구사항을 이미 지켜놓은 상태)

**2단계 — 공원 방문 + 방문객 보너스**

**3단계 — 공개 범위 세부 토글** (필요하면)

## 로컬 개발 환경 메모
- 백엔드: `cd backend && ./gradlew bootRun` (포트 8080). 실행 중인 프로세스 확인은 `lsof -i :8080`으로 — gradle daemon 특성상 `pkill -f 'gradlew bootRun'`으로는 실제 java 프로세스가 안 죽을 수 있음, PID 직접 kill 권장
- 프론트: `cd frontend && npm run dev` (포트 5173)
- DB: `docker exec cherry-mysql mysql -ucherry -pcherrypw1234 cherry -e "..."`
- 개발용 유저는 `DEV_USER_ID = 1L`로 컨트롤러에 하드코딩되어 있음 (인증 미구현 상태)
