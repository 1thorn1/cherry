# 체리 디자인 시스템

모든 UI 작업은 이 문서를 따른다.

---

## 무드

- **구조**: 깔끔한 모던 생산성 앱 (Amie, Things 3 계열)
- **색감**: 따뜻한 농장 톤 (베이지, 우드, 크림)
- **포인트**: 체리 레드

흰 배경에 회색 UI가 아니라, **크림빛 배경에 우드 계열 중성색**을 쓴다.

---

## 색

```css
:root {
  /* 배경 */
  --bg:            #FBF8F3;   /* 페이지 배경. 순백 금지 */
  --surface:       #FFFFFF;   /* 카드 */
  --surface-muted: #F3EEE6;   /* 세그먼트, 비활성 영역 */

  /* 텍스트 */
  --text:          #2E2A26;   /* 본문. 검정 금지 */
  --text-muted:    #8A8178;   /* 보조 */
  --text-faint:    #B8B0A6;   /* 시각, 플레이스홀더 */

  /* 선 */
  --border:        #E8E1D6;
  --border-strong: #D6CCBD;

  /* 포인트 */
  --cherry:        #C4485F;
  --cherry-soft:   #F7E6E9;

  /* 상태 */
  --done:          #7A9A6B;   /* 완료. 채도 낮은 녹색 */
  --done-soft:     #EBF0E6;
  --warn:          #C98A3C;
  --warn-soft:     #F8EEDF;

  /* 일정 블록 (파스텔) */
  --block-rose:    #F6E4E6;
  --block-sage:    #E6EDE2;
  --block-sand:    #F5EBDC;
  --block-sky:     #E3EAEF;
  --block-lilac:   #EDE7F0;
}
```

**규칙**

- 배경에 `#FFF` 쓰지 않는다. 카드만 흰색
- 텍스트에 `#000` 쓰지 않는다
- 일정 블록은 파스텔 배경 + 진한 텍스트. 채도 높은 단색 금지

---

## 타이포

```css
font-family: 'Pretendard Variable', Pretendard, -apple-system, sans-serif;
```

| 용도 | 크기 | 굵기 |
|---|---|---|
| 페이지 제목 | 28px | 700 |
| 섹션 제목 | 15px | 600 |
| 본문 · 태스크 제목 | 15px | 400 |
| 보조 · 시각 | 13px | 400 |
| 캡션 · 라벨 | 11px | 400 |

- 제목에 `tracking-tight` (letter-spacing: -0.02em)
- 본문 줄간격 1.5

---

## 간격

**4의 배수만 쓴다.**

```
4  8  12  16  20  24  32  40
```

| 위치 | 값 |
|---|---|
| 페이지 좌우 여백 | 20px (모바일) / 32px (데스크탑) |
| 카드 안쪽 | 16px |
| 카드 사이 | 8px |
| 섹션 사이 | 32px |

---

## 모서리

| 요소 | 값 |
|---|---|
| 카드 · 입력창 | 12px |
| 버튼 · 세그먼트 | 10px |
| 작은 태그 | 6px |
| 체크 원 | 999px |

---

## 그림자

**거의 쓰지 않는다.** 테두리로 구분한다.

```css
/* 필요할 때만 */
box-shadow: 0 1px 2px rgba(46, 42, 38, 0.04);
```

떠 있는 요소(모달, 드롭다운)에만 쓴다.

---

## 컴포넌트 규칙

### 태스크 카드

```
흰 배경 + 1px 테두리 + 12px 모서리
안쪽 여백 16px
왼쪽에 원형 체크 (20px)
제목 15px, 아래 시각 13px muted
오른쪽 끝에 보조 액션 (호버 시 노출)
```

- **완료 시**: 체크 원이 `--done`으로 채워지고 제목에 취소선 + `--text-muted`
- **구분선 대신 카드 간격**으로 나눈다

### 입력창

목록 **하단**에 카드와 같은 모양으로 둔다.

```
+ 할 일 적기
```

`+` 아이콘과 플레이스홀더. 포커스되면 테두리가 `--border-strong`.

### 세그먼트 탭

```
--surface-muted 배경 + 4px 안쪽 여백
선택된 것만 흰 배경 + 작은 그림자
```

### 주간 시간표

```
세로 시간축, 가로 7일
시간 라벨 11px --text-faint, 왼쪽 정렬
가로선 1px --border
일정 블록: 파스텔 배경 + 같은 계열 진한 텍스트, 6px 모서리
현재 시각에 --cherry 가로선
주말 열은 --surface-muted 배경
```

### 빈 상태

텍스트 한 줄로 끝내지 않는다. 아이콘이나 짧은 안내를 둔다.

```
아직 없어요
오늘 할 일을 하나 적어보세요
```

## 반응형

브레이크포인트는 **640 / 1024** 두 개만.

| 화면 | 레이아웃 |
|---|---|
| < 640 | 1단. 세그먼트 탭으로 전환. 하단 탭 바 |
| ≥ 1024 | 좌측 목록 + 우측 시간표. 하단 탭 없음 |

Tailwind 기준 접두어 없는 것이 모바일, `lg:`로 확장한다.

---

## 애니메이션

- `transform`과 `opacity`만 애니메이션한다
- 기본 150~200ms, `ease-out`
- 체크 완료는 200ms 안에 끝낸다
- `prefers-reduced-motion`을 반드시 처리한다

---

## 금지

| | 왜 |
|---|---|
| 순백 배경 `#FFF` | 차갑다. 농장 톤이 아니다 |
| 검정 텍스트 `#000` | 대비가 과하다 |
| 채도 높은 원색 | 무드가 깨진다 |
| 진한 그림자 | 테두리로 충분하다 |
| 4의 배수 아닌 간격 | 리듬이 깨진다 |
| 이모지 아이콘 | Tabler Icons를 쓴다 (stroke 1.5) |
